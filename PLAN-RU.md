# План: продукт со входом, кабинетами, чатом, админкой + все улучшения ML

## 1. Авторизация и пользователи
- БД: **SQLite + SQLAlchemy** (один файл, легко переносится на сервер; смена на PostgreSQL — одна строка).
- Вход по **email + пароль**, токены **JWT**, пароли хэшируются (bcrypt).
- Роли: **superuser (админ)** и **user**.
- Доступ выдаёт супер-пользователь: новый пользователь регистрируется → статус «ожидает», админ активирует/блокирует.
- Первый супер-пользователь создаётся из переменных окружения при старте.

## 2. Личный кабинет пользователя
- Дашборд с метриками и аналитикой работы системы: текущие сигналы (LONG/SHORT/FLAT, вход/стоп/тейк, плечо), точность моделей, profit factor, ожидание, история сигналов.
- Скринер всех 12 пар, плотности, кросс-биржевое сравнение, ML — как сейчас, но за логином.

## 3. Админка (супер-пользователь)
- Список пользователей, активация/блокировка, выдача доступа, смена ролей, сброс пароля.
- Просмотр активности.

## 4. Внутренний чат
- Реал-тайм через **WebSocket** + история через REST.
- Пользователь ↔ пользователь и пользователь ↔ поддержка (админ).

## 5. Улучшения ML (все 12 рекомендаций)
1. Балансировка классов (class_weight).
2. Калибровка вероятностей (isotonic/Platt).
3. Триплет-барьер (López de Prado) для разметки.
4. Признаки стакана в обучении.
5. Walk-forward валидация.
6. Комиссии и проскальзывание в бэктесте.
7. Динамический стоп по ATR.
8. Фильтр режима рынка (тренд/флэт).
9. Реальная maintenance margin для цены ликвидации.
10. WebSocket-стаканы.
11. Прокси/гео для Binance/Bybit (нужен прокси — уточню).
12. Персист обучения в БД + авто-переобучение по расписанию.

## 6. Запуск на сервере
- Бэкенд (FastAPI) + фронтенд (сборка Vite) разворачиваются как сервис.
- Дам Dockerfile/инструкцию для вашего сервера и/или разверну рабочий демо-инстанс.

## Решения по умолчанию (если не возразите)
- SQLite, JWT, bcrypt, роль-гейт по активации.
- Чат: WebSocket + REST.
- Супер-пользователь сидируется из env (логин/пароль вы зададите).
